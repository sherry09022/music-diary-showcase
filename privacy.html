이용하는 정보외부 처리보관과 삭제선택과 권리문의

안내 범위

음악일기는 음악 취향과 현재의 감정·감각을 살펴보고, 음악 감상 후 떠오른 말과 그림을 일기로 기록하는 앱입니다. 기본 iPhone 이용에는 별도의 음악일기 계정 가입이 필요하지 않습니다. 웹의 일부 AI 기능은 서비스 제공자의 로그인이나 접근 허용을 요구할 수 있습니다.

아래 내용은 현재 음악일기의 기능별 처리에 관한 안내입니다. 나의음악 앱이나 별도 공모전·차량용 데모는 기능과 정보 처리 방식이 다를 수 있습니다. Project SHU 기존 개인정보처리방침과 함께 확인할 수 있습니다.

이용하는 정보와 목적

기본 정보와 음악 취향
사용자가 선택한 연령대·성별, 평소 듣는 음악과 곡에 대한 선호를 온보딩, 대화의 맥락과 음악 추천에 사용합니다. 선택 항목은 건너뛸 수 있습니다.
대화와 음악일기
사용자가 말하거나 입력한 현재 상태, 감정, 음악에서 원하는 느낌, 몸의 감각, 떠오른 장면과 선택한 음악·그림을 대화 진행과 일기 작성에 사용합니다. 음성 인식 결과는 화면에 글로 표시됩니다.
연결과 서비스 운영 기록
앱 인증과 연결 상태 확인, 오남용·중복 요청 방지를 위해 가명 식별 정보, 요청·연결의 상태와 시각 등을 운영 서버에 보관합니다. 이 값은 이름이나 이메일을 직접 입력받는 방식과는 다르지만, 같은 이용 흐름을 구분하는 데 사용됩니다.
기기 진단 정보
iPhone에서 앱 버전, 음성·음악 재생 상태, 출력 종류, 음량, 오류 코드와 곡 식별 정보 등을 기기에 기록합니다. 음성 파일, 일기·대화 원문과 인증 비밀 값을 진단 로그에 담지 않도록 구성되어 있습니다.
문의 내용
이메일로 문의하면 회신 주소, 문의 내용과 사용자가 직접 보낸 파일을 문제 확인과 답변에 사용합니다. 문의에 필요하지 않은 일기 원문이나 다른 사람의 개인정보는 보내지 않아도 됩니다.

외부 서비스로 전달되는 정보

OpenAI 음성 대화

AI 음성 대화 안내에 동의하고 기능을 시작하면 마이크 음성, 대화 내용, 저장된 기본 정보, 현재 질문과 일기 답변이 OpenAI로 전달되어 음성 인식과 응답 생성에 사용됩니다. 대화를 정지하거나 글 입력으로 전환하여 AI 음성 연결을 멈출 수 있습니다.

OpenAI 그림 생성

장면 설명의 전송 안내에 동의한 후 그림을 요청하면, 설명 문장과 서비스 안전·오남용 방지에 쓰이는 가명 식별 정보가 OpenAI로 전달됩니다. 돌아온 그림 중 선택한 한 장을 일기에 저장할 수 있습니다. 그림 생성에 동의하지 않고 글로 일기를 남길 수도 있습니다.

AI 처리에는 개인적인 이야기 대신 꼭 필요한 내용만 입력할 수 있습니다. 타인의 이름·연락처나 민감한 정보를 장면 설명에 넣을 필요는 없습니다. 제공자의 처리·보관 기준은 OpenAI API 데이터 안내에서 확인할 수 있습니다.

Apple Music과 선택형 음성 인식

iPhone 전체 곡 재생은 Apple Music을 사용하며, 구독 상태와 접근 허용을 확인하고 곡 조회·재생 요청을 처리합니다. 웹에서는 Apple Music 미리 듣기를 제공합니다. Apple 계정 비밀번호나 결제 정보를 음악일기 입력창에 요구하지 않습니다. Apple의 음악 이용 정보 처리는 Apple Music 개인정보 안내를 따릅니다.

별도로 선택하는 기기 음성 인식이나 브라우저 음성 입력은 기기·브라우저에 따라 Apple 또는 해당 제공자의 서버에서 처리될 수 있습니다. 모든 음성 인식이 기기 안에서만 이루어지는 것은 아닙니다. iPhone 관련 안내는 Apple 음성 입력 개인정보 안내를 참고할 수 있습니다.

웹의 외부 추천 엔진

웹에서 ‘나의음악’ 추천 엔진이 연결되어 작동하는 경우, 상태·감정·감각·원하는 느낌·음악 취향·선택한 연령대와 가명 사용자 식별 정보가 추천 서비스에 전달될 수 있습니다. 이 경로에는 Google Firebase 익명 인증과 Supabase 기반 추천 서비스가 사용됩니다. iPhone의 기기 내 추천과 구분되며, 각 서비스의 안내는 나의음악 개인정보 안내, Google 개인정보처리방침, Supabase 개인정보처리방침에서 확인할 수 있습니다.

국외 처리와 연결 기록

외부 AI·음악·웹 제공자의 인프라에서 정보가 처리되므로 대한민국 밖에서 처리될 수 있습니다. 처리 위치와 제공자의 보관 기간은 서비스·계정 설정과 정책에 따라 달라집니다. 이 페이지에서 확인되지 않은 특정 국가, 무보관 설정이나 삭제 기간을 보장하지 않습니다. 본인의 이용과 관련된 상세 처리·삭제 문의는 Project SHU로 보내 주세요.

이 안내 페이지는 GitHub Pages에서 제공합니다. 페이지 방문 시 IP 주소 등 연결 기록은 호스팅 제공자가 처리할 수 있습니다. 페이지에 별도 분석 스크립트나 광고 코드는 넣지 않았습니다. GitHub 개인정보처리방침

보관과 삭제

기기에 저장되는 기록

iPhone의 기본 정보·대화 초안은 앱 저장 공간에, 완성된 일기와 선택 그림은 앱 내 웹 저장 공간에 보관됩니다. 웹앱의 기록은 이용한 브라우저의 사이트 저장 공간에 보관됩니다. 앱을 삭제하거나 사이트 데이터를 지우면 기록을 잃을 수 있으며, 기기 간 자동 동기화나 삭제한 기록의 복구는 제공하지 않습니다.

일기장에서 해당 일기를 열어 ‘일기 삭제’로 지울 수 있습니다. ‘내보내기’로 만든 파일이나 기기 백업에 남은 사본은 사용자가 별도로 관리해야 합니다. 앱 삭제와 개별 일기 삭제가 외부 제공자에게 이미 전송된 정보까지 자동으로 삭제하는 것은 아닙니다.

진단 기록

기기의 재생 진단 로그는 최대 7일, 2,000건 또는 약 1MiB 범위로 관리됩니다. 제한을 넘은 오래된 기록은 앱이 로그를 읽거나 쓸 때 정리합니다. 자동으로 운영자에게 업로드하지 않으며, 사용자가 ‘로그 공유’를 선택한 경우에만 공유 대상에게 전달됩니다. 공유·내보낸 파일은 이 기기 내 로그 정리와 별개입니다.

서버와 제공자 기록

운영 서버에는 인증·연결·요청 상태와 시간, 중복 요청 방지를 위한 식별 정보가 남습니다. 현재 이 기록 전체에 일괄 자동 삭제 주기는 적용되어 있지 않습니다. 계정 가입을 하지 않았거나 앱을 삭제했더라도 이 운영 기록이 함께 지워지는 것은 아닙니다. 확인·삭제를 원하면 아래 문의 창구로 요청할 수 있습니다.

AI 제공자의 처리·보관 및 이미 전송한 정보의 삭제는 해당 제공자의 정책과 적용 설정도 함께 확인해야 합니다. 모든 AI 입력이 즉시 삭제되거나 운영자가 모든 사본을 직접 지울 수 있다고 보장하지 않습니다. 문의 메일과 사용자가 보낸 진단 파일의 보관·삭제에 대해서도 같은 창구로 요청할 수 있습니다.

선택과 권리 행사

  1. 음성 사용 중단: 대화를 정지하거나 글 입력으로 전환할 수 있습니다. 기기·브라우저 설정에서 마이크·음성 인식 권한을 끌 수도 있습니다.
  2. 그림 전송 거절: 생성 안내에 동의하지 않으면 새 AI 그림 요청을 보내지 않습니다. 그림 없이 일기를 작성할 수 있습니다.
  3. 기록 관리: 일기 삭제, 표시되는 내보내기 기능, 기기·브라우저 데이터 관리 기능을 이용할 수 있습니다. 전체 기기 데이터를 지우기 전 필요한 기록을 먼저 보관해 주세요.
  4. 열람·정정·삭제·처리 중단 문의: shu@project-shu.org로 요청할 수 있습니다. 이용한 기기 종류와 대략적인 이용 시점을 알려 주세요. 요청 범위를 확인한 뒤 처리 가능 여부와 결과를 안내하겠습니다. 비밀번호나 인증번호는 요구하지 않습니다.

해당 기능의 정보 전송을 거절하거나 권한을 철회하면 AI 음성·그림 등 그 정보가 필요한 기능은 제한될 수 있습니다. 이미 외부로 전송된 정보의 처리 중단·삭제는 별도 확인이 필요합니다.
