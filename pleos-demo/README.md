# 음악일기 · Pleos Connect 별도 데모

**[웹 데모 열기](https://sherry09022.github.io/music-diary-showcase/pleos-demo/)** · **[Android SDK 프로젝트](android/)** · **[빌드 결과](https://github.com/sherry09022/music-diary-showcase/actions/workflows/pleos-demo.yml)**

기존 음악일기 iPhone 앱, 운영 웹앱, 홍보 릴스와 분리된 공모전용 개발 데모입니다. 이 폴더만으로 동작하며 운영 앱의 계정·인증키·사용자 데이터를 포함하지 않습니다.

## 설치 파일과 검증

APK는 Pleos 서비스가 있는 차량용 Android 환경을 위한 **debug 데모**입니다. 일반 스마트폰용 설치 파일이나 App Market 배포판이 아닙니다. 실제 Pleos 런타임·마이크·스피커 검증은 아직 완료하지 않았습니다. [별도 에뮬레이터 실행 절차](android/EMULATOR.md)는 약관 확인 후 수동으로 진행합니다.

## 바로 체험하기

웹페이지의 **전체 시연**을 누르면 취향 → 상태와 감정 → 음악에서 원하는 느낌 → 몸의 감각 → 세 곡 맛보기 → 곡 선택 → 감상 → 주차 후 심상 기록 → 일기 저장을 한 번에 볼 수 있습니다.

**직접 체험**에서는 연령대·선택적 성별·평소 듣는 음악을 먼저 입력하고, 세 곡을 들어 취향을 고릅니다. 음성·예시 버튼·글 입력을 사용할 수 있습니다. ‘화가 나요’처럼 이미 감정을 말하면 감정을 다시 묻지 않고 음악에서 필요한 느낌으로 이어집니다. ‘두 번째 곡 추천해 줘’, ‘두 번째 곡을 선택할게요’, ‘다른 곡을 들을래’, ‘이 곡이 좋겠어요’를 인식합니다. 인식된 문장은 바로 표시하고 마지막 입력 후 5초에 이어갑니다.

웹 음성인식은 브라우저 지원과 마이크 권한이 필요합니다. 지원하지 않으면 예시·글 입력으로 체험할 수 있습니다. 시작 버튼의 사용자 동작 이후 음악과 안내 음성을 재생합니다. 마이크는 안내·음악 재생 중 멈추며, 화면을 떠나거나 중지 버튼을 누르면 해제합니다. **전체 소리 끄기**는 음악과 음성을 함께 음소거하며 이 브라우저에 저장되어 새 시연·새로고침 후에도 유지됩니다. **음성·음악 멈춤**은 자동 시연과 녹화를 중단하며 예약된 단계가 나중에 음악을 다시 재생하지 않도록 취소합니다.

## 실제 구현과 모의 구현

| 항목 | 공개 웹 데모 | Android 네이티브 앱 |
| --- | --- | --- |
| 화면·대화 흐름 | 실제 실행되는 Canvas + JavaScript | 같은 웹 파일을 APK assets로 포함 |
| 음성 입출력 | 브라우저 STT/TTS. 자동 시연은 미리 합성한 예시 음성 | 실제 Pleos SpeechToText/TextToSpeech 3.3.1의 ON_DEVICE 모드 |
| 음악 | 3개의 라이선스 음원 발췌가 실제 재생됨 | Android MediaPlayer + 오디오 포커스 |
| 차량값 | 명시적인 모의 주행/주차 입력 | Vehicle 2.3.2 실제 capability/브레이크 페달 조회 |
| 화면 제한 | 모의 주행 중 기록·폼 제한 | 실제 AAOS CarUxRestrictionsManager 결과, 알 수 없는 상태도 제한 |
| 음악 추천 | 세 곡의 취향·감각 태그를 비교하는 로컬 규칙 | 같은 로컬 규칙. 기존 추천 서버 연결 아님 |
| 심상 그림 | 미리 제작한 포근한 이불 예시. 다른 내용이면 글만 저장 | 동일. 실시간 생성 API 호출 없음 |
| 일기 | 이 브라우저의 localStorage | 앱 WebView의 localStorage |

**웹 영상은 Pleos SDK 실행 영상이 아닙니다.** 화면에 이 구분을 계속 표시합니다. 네이티브 소스는 공식 SDK 바이너리의 실제 API 서명을 확인해 작성했고, 공개 CI에서 컴파일·lint를 수행합니다. 실제 Pleos 에뮬레이터/차량에서 서비스 연결·마이크·스피커를 검증한 상태는 아닙니다. APK 설치 및 실제 장치 검증은 [Android 안내](android/README.md)를 참고하세요.

브레이크 페달을 주차 판단에 사용하지 않습니다. 네이티브의 물리적 `parked` 값은 알 수 없는 상태이며, 전체 UI 허용은 AAOS의 `uxRestricted === false`일 때만 가능합니다. 주행 시 전방에 집중하는 음악 감상만 제시하고 몸에 몰입하는 안내·심상 이미지·일기 편집은 제한합니다. 차량의 운전자 주의 분산 인증이나 Pleos App Market 승인을 받은 제품은 아닙니다.

## 실행·검증

```bash
# 저장소 루트에서
python3 -m http.server 4186
# http://localhost:4186/pleos-demo/

node --check pleos-demo/app.js
node --test pleos-demo/*.test.mjs

# Android SDK/JDK 17이 있는 개발 환경에서
cd pleos-demo/android
./gradlew :app:assembleDebug :app:lintDebug
```

외부 npm 패키지나 API 키가 필요하지 않습니다. 로컬 웹 서버는 브라우저 ES modules를 위해 필요합니다. 마이크는 HTTPS 또는 localhost에서 사용하세요.

회귀 검증은 일반적인 곡 선택 문장, 부정적 감정 이후 원하는 느낌의 추천, 다른 감각에 따른 추천 순서, 차량 상태 불명 시 기록 제한, 심상과 맞지 않는 예시 그림을 붙이지 않는 동작을 확인합니다. 안내 중 중단하면 나중에 음악이 다시 시작되지 않는지 웹·네이티브 경로에서 확인하고, 저장된 전체 음소거가 새 재생에서도 유지되는지 검증합니다.

## 시연 영상 캡처

**시연 화면 녹화** 버튼은 현재 실행하는 앱의 실제 Canvas 화면을 `captureStream(30)`과 `MediaRecorder`로 녹화합니다. 자동 시연의 안내 음성과 음악도 Web Audio로 함께 수록합니다. 정지 이미지를 이어 붙인 영상이 아닙니다. 녹화 완료 후 **녹화 영상 저장**을 누르면 WebM 또는 지원되는 MP4가 내려받아집니다. 브라우저에 따라 녹화를 지원하지 않을 수 있습니다.

자동 시연의 대답은 데모 시나리오이며 실제 마이크 인식 결과가 아닙니다. 화면에도 자동 시연·예시 대화라고 표시합니다. 실제 음성인식은 **직접 체험 → 마이크로 대화**에서 확인합니다.

## 공개 데이터와 권리

- 방문자의 답변·일기·취향은 이 브라우저에만 저장합니다. **이 기기의 데모 기록 삭제**로 지울 수 있습니다.
- 진단 로그는 브라우저 메모리의 이벤트명·오류 코드만 기록하며 인식 문장을 로그에 넣지 않습니다.
- 브라우저의 음성인식은 브라우저 제공자의 서비스를 이용할 수 있습니다. Pleos ON_DEVICE 경로에는 외부 API 키가 없습니다.
- 음원·AI 예시 이미지 출처와 편집 내용은 [CREDITS.md](CREDITS.md)에 명시했습니다.
